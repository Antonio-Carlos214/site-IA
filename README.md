# Polícia Civil - Página Informativa

## Descrição

Este projeto consiste em uma página informativa sobre a Polícia Civil,
apresentando sua importância para a sociedade, suas principais funções,
a atuação na investigação criminal e sua relação com a segurança pública.

O projeto foi desenvolvido como atividade acadêmica para demonstrar
conhecimentos de desenvolvimento web, organização de conteúdo,
acessibilidade, responsividade e versionamento de código.

## Tema escolhido

**Polícia Civil e sua atuação na sociedade.**

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Recursos utilizados

A página utiliza:

- Estrutura semântica HTML5;
- Layout responsivo;
- CSS Grid;
- Menu de navegação;
- Imagens com atributo `alt`;
- Listas ordenadas e não ordenadas;
- Citações com `<blockquote>`;
- Efeitos `:hover`;
- Design adaptado para computadores e celulares.
